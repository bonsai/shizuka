### 課題
- BQ CLI の JSON 出力が全数値を文字列として返す → `_convert_row()` で型変換
- BQ は DEFAULT 制約非対応 → 全カラム nullable + Python 側でデフォルト処理
- SQLite DDL (schema.sql) と BQ DDL (bq_ddl.sql) を二重管理する必要
- マルチラインSQLを `bq query` に直接渡せない → `" ".join(sql.split())` でフラット化

### ナイスアイデア
- BQ JSON の型問題は `_convert_row()` で一括解決。`_NUMERIC_KEYS` セットで型変換対象を管理
- `CREATE OR REPLACE TABLE ... AS (SELECT * FROM UNNEST([...]))` で seed と schema を一度に実行
- `--backend local|bq` の切り替えでローカル開発と本番を使い分け可能

### 発見
- `bq` CLI は PowerShell から直接呼べない (cmd.exe 経由 or `python subprocess` で cmd.exe /c bq)
- BQ `MERGE` 文は `INSERT OR REPLACE` の代わりに使える (upsert パターン)
- `usage_log` の PARTITION BY DATE(logged_at) で日付単位のクエリが効率的に
